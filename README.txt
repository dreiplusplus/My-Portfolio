DREII++ — PERSONAL FIELD-NOTES PORTFOLIO
================================

FILES
- index.html      Home page
- about.html      About Me page
- skills.html     Skills page
- projects.html   Projects page (includes both GitHub repositories)
- contact.html    Contact page
- style.css       External CSS for the design and responsive layout
- script.js       External JavaScript interactions

HOW TO OPEN
1. Extract the ZIP file.
2. Open index.html in a browser.
3. Click Home, About Me, Skills, Projects, and Contact to navigate.

BEFORE SUBMITTING
1. In contact.html, replace "Replace with your email" and "Replace with your number" with the contact information you want to share.
2. Review the About Me and Skills text so it accurately represents you.
3. Make sure all activities you need to submit are linked in projects.html. The two supplied GitHub repositories are already linked.
4. Upload the extracted website files to a GitHub repository if you want to deploy it with GitHub Pages.

GITHUB PAGES QUICK STEPS
1. Create a new public repository on GitHub.
2. Upload all five HTML files, style.css, script.js, and this README.
3. Open repository Settings > Pages.
4. Under Build and deployment, select "Deploy from a branch", choose main and /(root), then Save.
5. Wait for GitHub Pages to publish your website, then submit the published URL to your teacher.

JAVASCRIPT FEATURES
- Dark/light mode toggle
- Welcome message button
- Show/hide personal interests
- Contact form demo confirmation
- Responsive mobile navigation
- Back-to-top links

NOTE
The contact information directory is a front-end demonstration only; it does not send messages to an email or server.


DESIGN NOTE
This version uses an original warm-paper, notebook-inspired visual style with orange and blue accents, custom CSS illustrations, and student-focused wording. It is not intended to reproduce the reference portfolio.
